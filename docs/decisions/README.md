# Architectural decision records

This directory records repository-level choices that affect scientific
provenance, publication, experiment organization, or long-lived developer
workflows. Decision records explain why a choice was made, the alternatives
considered, the evidence that would falsify it, and when it should be revisited.

Decision records are durable history. A later decision may supersede an older
one, but completed records are not silently rewritten.
