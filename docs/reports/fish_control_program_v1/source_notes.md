# Source notes

- `program_portfolio.sql` is a report-local transcription of the validated
  program manifest and generated readiness audit. The machine-readable
  authority remains `examples/fish_control_program.example.json`.
- `history_evidence.sql` contains reviewed checkpoint values from versioned
  repository artifacts summarized in
  `docs/programs/fish_inverse_control/EXPERIMENT_HISTORY.md`.
- Literature links in the report point to primary papers or official journal
  pages. Literature motivates experiment design; it does not substitute for
  evidence from this dataset.
- All planned job counts exclude the three manual annotation/data-readiness
  checkpoints, which intentionally have zero compute jobs.
