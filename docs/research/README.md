## Interpretation rule

Keep these evidence classes separate:

1. neuron/activation measurement;
2. passive neural-state forecasting;
3. causal pre-movement intent decoding;
4. action-conditioned system identification;
5. simulated and deployed control.

A downstream claim must cite its own evidence and cannot inherit validity from
an upstream result.

`docs/archive/plans/VISIONS.md` preserves the broad research journal, but its
older checkpoints do not override current program gates.

## Document status vocabulary

- **Plan** specifies a future experiment and contains no result.
- **Results** reports completed repository evidence with explicit limitations.
- **Current state** summarizes accepted claims without replacing their sources.
- **Generated story** is rebuilt from the canonical YAML ledger and must not be
  edited directly.
- **Historical** documents remain useful provenance but do not override newer
  gated results.
