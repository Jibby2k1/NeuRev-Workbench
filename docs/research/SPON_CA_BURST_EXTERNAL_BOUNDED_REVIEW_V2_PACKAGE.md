# Spon Ca Burst external bounded-review v2 package

Status: implementation complete; independent annotations pending.

The repository now contains two separately distributable browser annotation
archives and a private administrator archive. Phase A is Raw-first and
exhaustive within a frozen enriched 192×192 region. Phase B contains 18
re-randomized, re-blinded six-panel candidates and is released only after the
reviewer's Phase A submission is locked.

The package does not contain a research result. It creates the human-gated
evidence needed to test local detector precision/recall, source identity,
candidate-review reproducibility, and the relationship between processed
representations and reviewer decisions.

## Validated inventory

- 4 Raw-first videos;
- 18 assisted full-trace videos;
- 3 integrity-checked ZIP archives;
- 54 indexed package artifacts;
- zero public text/path blinding findings;
- coordinate, submission, randomization, archive, media, and agreement tests;
- portable local browser applications with locked JSON exports.

## Evidence boundary

No second-reviewer label, adjudicated truth, precision, or recall estimate has
yet been produced. Completion of the software and media package must not be
reported as confirmation of the detector or biological source claims.
