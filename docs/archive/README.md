# Documentation archive

This directory preserves historical plans, journals, and implementation briefs
that remain useful for provenance but no longer define current repository or
scientific state.

Use the [repository guide](../REPOSITORY_GUIDE.md), generated
[research story](https://github.com/Jibby2k1/NeuRev-Workbench/blob/main/research/generated/PROJECT_STORY.md), and canonical
[`research/registry/`](https://github.com/Jibby2k1/NeuRev-Workbench/tree/main/research/registry) for current authority.

Archived material may contain superseded paths, statuses, priorities, or
interpretations. It is retained intact where possible; moving a file here does
not promote or invalidate a scientific claim.
