# Legacy reporting

This directory supports the historical root-level grid-search pipeline and is
retained so earlier analyses remain reproducible. It is a compatibility
surface, not the home for new development.

Put maintained research-story and report code under [`neurobench`](../neurobench/)
or the relevant experiment package, and consult the
[codebase navigation guide](../docs/CODEBASE_NAVIGATION.md) before changing
legacy behavior.
